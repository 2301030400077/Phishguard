Transparent model reporting.

PhishGuard uses the URL text and a shared lexical feature extractor. It does not use the dataset's precomputed webpage features.

Dataset source

PhiUSIIL Phishing URL (Website), UCI Machine Learning Repository (Prasad & Chandra, 2024). The repository describes 235,795 URLs: 134,850 legitimate and 100,945 phishing. Dataset labels are 1 for legitimate and 0 for phishing; PhishGuard maps these to 0 legitimate and 1 phishing.

The training script uses only the URL and label columns, removes missing, invalid, repeated, and conflicting URL records, and groups the train/test split by hostname. The UCI data includes webpage-derived fields; these are excluded to keep training aligned with URL-only prediction.
