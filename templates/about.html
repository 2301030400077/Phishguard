ABOUT THE PROJECT

Make URL risk easier to understand.

PhishGuard is a university minor project exploring explainable machine learning for phishing URL detection.

Project objectives

  • Extract measurable characteristics from URL text.
  • Train a Random Forest classifier on a documented labelled dataset.
  • Explain model outputs with feature contributions.
  • Encourage careful link handling without claiming a prediction guarantees safety.
